# Паспорта корпусов и нормативная база — Issue #5

**В публичном MIT-репозитории нет предустановленного нормативного корпуса русского языка.** Публикация частотных таблиц без проверки прав на исходные данные и их производные запрещена. norm_letter_deviation остаётся unavailable/null.

Проверенные источники и ограничения: [корпусный обзор](../../references/corpus-license-review.md). Математический расчёт по **собственной локальной, ненормативной** базе: [контракт A2](../../references/a2-contract.md).

## Требования к будущему нормативному корпусу

Для каждого допущенного источника потребуются: источник и точный URL; авторы/правообладатели; действительная лицензия на первичный корпус и производные частотные таблицы; явное разрешение коммерческого использования/перераспространения; жанры, годы, репрезентативность, версия и дата snapshot; полная хеш-сумма исходных данных; объём русских букв; метод очистки/нормализации, контрольные суммы полученного профиля; атрибуция и порядок отзыва. Ни одного корпуса, отвечающего этим требованиям, на данном этапе не одобрено.

Профиль пользователя может иметь только статусы user_supplied_non_normative и self_declared_unverified; он не приобретает статус «нормы» независимо от числа букв. Код MIT не автоматически распространяет MIT на сторонние корпусные данные.

Никаких исходных данных, таблиц частот, API, n8n, серверов или автоматических скачиваний сюда не добавлено.
