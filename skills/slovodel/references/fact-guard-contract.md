# A8 — контроль защищённых фактов при переписывании (rules 2.0)

**Статус:** офлайн-модуль публичного навыка, Core 0.8.0, `guard_version: a8-rules-2.0`. Это **детерминированный скрининг расхождений**, а не доказательство смысловой эквивалентности. A8 **не измеряет** психологическое воздействие и не заменяет редактора, юриста или согласование публикации.

## Когда запускать

При `rewrite` и `compare` A8 уже входит в `scripts/workflow.py` — отдельно его запускать не нужно. Самостоятельный вызов нужен, когда проверяют только факты:

```bash
python skills/slovodel/scripts/validate.py --before original.txt --after edited.txt
python skills/slovodel/scripts/validate.py --before original.txt --after edited.txt --protected-file protected.txt
```

`protected.txt` — по одной точной фразе на строку (≤100 строк, ≤256 символов): «согласование с редактором», «письменное согласие», название проекта. **Не записывай** туда пароли, токены и личные данные.

## Два уровня находок

| Уровень | Что значит | Решение |
|---|---|---|
| `blocker` | Изменился распознанный факт | `decision: blocked`, код выхода **5**. Готовый к публикации вариант запрещён до подтверждения автором |
| `review` | Изменились слова-условия или слова охвата, которые часто меняют смысл, но так же часто перефразируются | `decision: review_required`, код **0**, предупреждение `CONDITION_OR_SCOPE_WORDING_CHANGED_REVIEW`. Агент обязан сам сверить условие и назвать его в «Чего не хватает», если оно ослабло или усилилось |

## Категории

| Категория | Уровень | Примеры, которые ловит | Ограничения |
|---|---|---|---|
| `url`, `email` | blocker | ссылка, адрес почты | Распространённые формы, не полный парсер |
| `money` | blocker | `80 000 ₽` = `80 тыс. руб.` (одна сумма) | Суммы словами — в `number_word` |
| `date`, `deadline` | blocker | `15.10.2026`, `15 октября`, `до пятницы` | Разные записи одной даты консервативно блокируются |
| `calendar` | blocker | `в пятницу` → `в субботу`, `в октябре` → `в ноябре` | Только дни недели и месяцы |
| `range`, `quantity`, `number` | blocker | `от 5 до 7 дней`, `10%`, `20 часов в неделю`, телефоны, время `10:00` | Шаблонные единицы |
| `number_word` | blocker | `три дня` → `пять дней`, `первое` → `второе`, `пять тысяч` | Количественные 0–1 000 000 000 и порядковые 1–10. Замена `три` ↔ `3` тоже блокируется — подтвердите |
| `code` | blocker | промокоды и модели с цифрами: `OSEN10`, `5G`, `COVID-19` | — |
| `binding` | blocker | **перестановка** значений: «сайт 100 000 ₽, лендинг 30 000 ₽» → наоборот | Привязка к ближайшему слову (≤3 слов назад в той же части предложения); при перестройке фразы привязка может не найтись — тогда находки нет |
| `organization`, `person` | blocker | `ООО «Альфа»`, `Иван Иванов` | Узкие шаблоны |
| `proper_name` | blocker | одиночные фамилии, города, бренды, латиница: `Петрова` → `Иванова`, `Ижевск` → `Казань`, `Wildberries` → `Ozon` | Слова с заглавной не в начале предложения и латинские слова; падежи сводятся упрощённым отсечением окончаний |
| `polarity` | blocker | `возможен` → `невозможен`, `не требуется` → `требуется`, `можно` ↔ `нельзя`, `бесплатно` ↔ `платно`, `разрешено` ↔ `запрещено`, `всегда` ↔ `никогда` | Срабатывает, если слово осталось, а отрицание у него появилось или пропало; область отрицания не анализируется |
| `modality` | blocker | `может` → `должен`, `вправе` → `обязан` | Только явные модальные слова |
| `guarantee` | blocker | появилось или пропало «гарант…» | См. [compliance.md](compliance.md) |
| `protected_term` | blocker | фразы из `--protected-file` | Точное совпадение без синонимов |
| `condition` | review | `если`, `только`, `после`, `без`, `не`, `обязательно`… | Перефраз «если оплатите» → «при оплате» не блокирует, но требует сверки |
| `quantifier` | review | `большинство` → `все`, `часто` → `всегда` | Только список слов охвата |

Значения, имена, привязки и фразы в отчёт **не попадают** — только категории и счётчики. Для `polarity` и `modality` счётчики означают число обнаруженных переворотов.

## Решения

- `blocked` — есть хотя бы одна находка `blocker`. Скрипт никогда сам не снимает блокировку.
- `review_required` — тексты различаются, блокирующих находок нет. Находки `review` перечислены в `findings`. **Не означает** эквивалентность.
- `unchanged` — строки идентичны.

Всегда `publish_ready: false`, `semantic_equivalence: not_verified`. Коды выхода: `0` (`review_required`/`unchanged`), `5` (`blocked`, JSON всё равно выводится), `3` (вход/фразы), `4` (вывод), `2` (аргументы).

## Проверено тестами (tests/test_v08.py)

- 21 реальное искажение фактов — все `blocked` со своей категорией; 3 изменения охвата — `review_required` с находкой `review`.
- 18 смыслосохраняющих перефразов, включая целые посты, — ни один не `blocked`.
- 1 МиБ текста обрабатывается за линейное время (было до 152 с из-за квадратичного алгоритма); худший найденный вход — 1 МиБ почти из одних чисел — около 3 с, типичный текст 1,5–2 с. Время зависит от машины.

Наборы синтетические и составлены под типичные правки копирайтера; это не гарантия на любых текстах.

## Известные ограничения

1. Нет семантического анализа и полноценного NER: «не обязан» → «не запрещено» может пройти как `review_required`.
2. Перестройка предложения иногда отвязывает число от слова — тогда `binding` молчит, а сам факт проверяется категорией числа.
3. Упрощённое отсечение окончаний: разные слова с общей основой могут совпасть, а нестандартные формы имён — не совпасть.
4. Смена записи (`три` ↔ `3`, `15.10.2026` ↔ `15 октября`, `по Москве` → `московское время`) блокируется консервативно — подтвердите вручную.
5. Нет автоматического извлечения обязательных фраз из брифа — передайте их через `--protected-file`.
6. Только файлы до 1 МиБ; ограничения на симлинки и перезапись — как в [CLI-контракте](cli-contract.md).
