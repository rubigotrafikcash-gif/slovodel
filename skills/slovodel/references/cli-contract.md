# Issue #3 — CLI и контракт офлайн-каркаса

**Статус:** минимальное исполняемое ядро, без лингвистических измерений. Версия: `0.1.0`, schema `1.0.0`. Это независимый публичный инструмент, не оригинальная программа «Словодел»/«Диатон».

## Требования

- Python **3.10 или новее**, только стандартная библиотека в момент исполнения.
- Нет собственного сервера, API, ключей, n8n или подключения к сети.
- Вход: **существующий обычный UTF-8 файл**, максимально 1 048 576 байт (1 MiB), включая пустые файлы; BOM допускается и учитывается при хешировании.
- Символические ссылки на входной файл отклоняются; FIFO и устройства — тоже. Ограничение: в этой версии не обеспечена защита от ссылок в **родительских каталогах** и не изолируется окружающая файловая система; агент должен запускать код в доверенном локальном окружении.
- Вывод по умолчанию в stdout, либо в **новый** файл через `--output`, создаваемый эксклюзивно (старые файлы никогда не перезаписываются), права 0600 на POSIX. Имена путей и содержимое текста не включаются в сообщения об ошибке.

## Команды

```bash
python skills/slovodel/scripts/analyze.py --input input.txt --mode audit --format json
python skills/slovodel/scripts/analyze.py --input input.txt --output audit.json
python skills/slovodel/scripts/compare.py --before before.txt --after after.txt --output comparison.json
python -m unittest discover -s tests -v
```

Запускать из каталога репозитория или по абсолютным путям. После копирования каталога `skills/slovodel` команды доступны внутри этого каталога: `python scripts/analyze.py ...` и `python scripts/compare.py ...`. Пакет `slovodel_core/` расположен **внутри навыка** — внешняя установка через `pip` не требуется. При желании проект можно упаковать через корневой `pyproject.toml`, но установка пакета необязательна.

## Что действительно работает

- Валидация входного файла и строгое декодирование UTF-8.
- SHA-256 **оригинальных байтов**, без изменения файла.
- Подготовка **копии в памяти** с Unicode NFC и флагом, изменилась ли строка; карта смещений между исходником и NFC **ещё не реализована**.
- Детерминированные `audit` и `compare` с версионными JSON-отчётами.
- Маркировка **всех неподдерживаемых** метрик как `unavailable`, значение `null`.
- Сообщение о невозможности исторических расчётов: `historical_compatibility = not_verified`.

**Что не работает до следующих Issues:** токенизация, частоты, слоги, лингвистические дельты, POS, нормативные корпуса, fact guard, Jauravlev/Cherepanova и исторические шкалы, AI-редактура из Python. Клиент не должен утверждать, что эти расчёты проведены. В `compare` намеренно возвращается `comparison_status: unavailable` и пустые `comparisons: []`, даже при сравнении идентичных файлов: нельзя заявлять нулевую числовую дельту без измерителя.

## Формат и отслеживаемость

- `schemas/analysis.schema.json`, `schemas/compare.schema.json` — **публичные JSON Schema Draft 2020-12**.
- Поля аудита: `schema_version`, `tool_version`, `mode`, `language` (целевой русский, **определение языка не выполняется**), `language_detection`, `source_sha256`, `source` (хеш, байты, NFC), `source_policy`, `measurements`, `historical_compatibility`, `warnings`, `errors`.
- Поля сравнения: те же общие метаданные, `before`, `after`, `measurement_method_version`, `comparison_status`, `comparisons` (пока пусто).
- Метрика: `id`, `value`, `unit`, `status`, `method_id`, `method_version`, `dataset_id`, `n`, `warnings`. Пока все `unavailable` и `null`.
- Исходные тексты **не включаются** в отчёт. Из отчёта можно узнать размер и SHA-256; хеш может раскрыть соответствие известному тексту, поэтому не публикуйте отчёты конфиденциальных материалов без согласования.
- Отчёт не сохраняется на диск автоматически: только при явном `--output`. Обычный stdout может сохраняться самой агентской средой — необходимо учитывать её правила.

## Коды выхода

| Код | Значение |
| --- | --- |
| 0 | Успех, создан отчёт |
| 2 | Ошибка параметров CLI (`argparse`) |
| 3 | Некорректный/недоступный вход |
| 4 | Ошибка записи результата, включая существующий выходной файл |

Стандартный stderr содержит только фиксированный `SLOVODEL_ERROR: <КОД>`, никаких фрагментов текста. Исключение: argparse может показать недопустимое **значение аргумента** (например, неверное `--mode`); не передавайте содержимое текста в CLI-аргументах.

## Тесты

`tests/test_cli.py` использует стандартный `unittest`. Проверяются неизменность байтов, детерминизм, честные unavailable, отрицательные случаи UTF-8/размера/ссылок/перезаписи, режимы, режим пустого текста, JSON-контракт. При наличии **необязательного** пакета `jsonschema` дополнительно проверяются полные схемы Draft 2020-12. Наличие теста не означает его успеха — фактические результаты должны быть приведены в Issue #3.

## Ограничения безопасности

Нет сетевых библиотек/сетевых вызовов в коде, но локальный Python-процесс по умолчанию не помещён в сетевой sandbox ОС. Не запускайте недоверенные модули и не выдавайте обещание защиты от внешних Python-hook/окружения. Значение `network_access: false` означает, что **данный код не инициирует сетевые запросы**, а не гарантию отсутствия сетевого доступа у интерпретатора.
