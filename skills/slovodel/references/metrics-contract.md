# Измеримые метрики СловоДела: правила A1/A3/A4/A6/A7 (Issue #4)

Статус: **спецификация измерителей A1/A3/A4/A6/A7**, первично реализованных в Python Core 0.2.0. С версии 0.4.0 добавлена отдельно включаемая морфология A5 (см. [отдельный контракт](morphology-contract.md)); методы измерений теперь маркируются действующей версией Core. Для базовой работы внешние зависимости не нужны. Алгоритмы и тесты находятся в `slovodel_core/metrics.py` и `tests/test_metrics.py`.

## 1. Общие правила и ограничения

- Обрабатывается **копия Unicode NFC**; исходные UTF-8 байты неизменны и отслеживаются SHA-256. `offset_map_status=not_implemented` — нельзя вычислять точные координаты выделения в исходнике после NFC.
- Процесс не выполняет распознавание языка, транскрипцию речи, лемматизацию, синтаксический разбор, работу со словарями или нормативными корпусами. `language: ru` — целевой профиль, а не обнаруженный язык.
- URL с `http(s)://` и `www.`, а также адреса электронной почты исключаются из **токенизации и частот** простой регулярной маской, сохраняющей длину строки. Это не полный URL/email-парсер и не удаление HTML/Markdown/кода; нестандартные записи, телефоны, хэштеги, внутрисловные ссылки, код в кавычках могут изменить подсчёты.
- Токен — последовательность Unicode-букв с прикреплёнными комбинируемыми знаками; ASCII дефис (`-`), U+2010 и U+2011 между буквами склеивают в один токен и нормализуются к `-`. Длинное тире, пунктуация, цифры, подчёркивание разрывают токен. `A_Я` → два токена; `текст42` → один буквенный токен `текст`, цифровой фрагмент не включён.
- `token_count` считает буквы **всех письменностей**. Для русских метрик `russian_token_count` учитывает только токены из 33 русских букв `абвгдеёжзийклмнопрстуфхцчшщъыьэюя` (с возможными диакритиками/дефисами). Смешанный латинско-русский токен не является русским.
- С метода 0.8.0 перед подсчётом: мягкий перенос (U+00AD), zero-width (U+200B–U+200D), word joiner (U+2060) и BOM **внутри слова** удаляются; апостроф между буквами склеивает токен (`д'Артаньян`); токен, в котором есть русские буквы, а все латинские буквы — двойники (`a c e o p x y A B C E H K M O P T X`), читается как русский. Число таких токенов и невидимых символов выводится отдельно (раздел 10).
- `е` и `ё` всегда разные буквы после NFC и приведения регистра. Ничего не переводим в транскрипцию, поэтому не говорим об аллитерации/ассонансе как **измеренной звуковой** характеристике.
- JSON содержит только **агрегированные числа**, не списки слов/исходные n-граммы. Хеш и длина потенциально могут считаться персональными метаданными; отчёт не содержит дословного текста.
- Каждая метрика: `id`, `value`, `unit`, `status`, `method_id`, `method_version`, `dataset_id`, `n`, `warnings`. Для реализованных — `reproducible`, `method_version=0.2.0`, `dataset_id=null`; для недоступных — `unavailable`, `value=null`. Поле `n` отражает размер основы подсчёта (токены/русские буквы/окна), указанный в конкретном методе; оно не обязано совпадать с `value`.

## 2. A1 — токены, предложения, буквы, графемоподобные кластеры

| Метрика | Правило/единица |
|---|---|
| `token_count` | Число всех буквенных токенов после маскирования URL/email; tokens |
| `russian_token_count` | Число токенов только из русского алфавита; tokens |
| `sentence_count` | Число непустых (с буквенным токеном) сегментов, разделённых `.`, `!`, `?`, `…` и (с 0.8.0) переводом строки, если следующая строка не начинается со строчной буквы; sentences |
| `unicode_codepoint_count` | Число Unicode code points во **всей NFC-копии**, включая пробелы, ссылки и пунктуацию; codepoints |
| `base_mark_cluster_count` | Число символов, категория которых в Unicode **не** `M*`; clusters |
| `russian_letter_count` | Количество русских букв `RU_ALPHABET` в тексте, включая русские части смешанных токенов; letters |
| `letter_а_count` … `letter_я_count` | 33 отдельные метрики числа букв, в том числе `е` и `ё`; letters |

**Предложения — эвристика.** Защищены часто встречающиеся сокращения: `т. д.`, `т. п.`, `г.`, `ул.`, `им.`, `см.`, `напр.`, `др.`, `стр.`, `рис.`, `проф.`; точка между цифрами в десятичной записи не считается границей. Прямая речь, инициалы, сложные сокращения, Markdown и другие нестандартные конструкции могут быть посчитаны ошибочно. Это не синтаксический разбор.

**Графемы.** `base_mark_cluster_count` — **приближение на основе категорий Unicode**, не алгоритм UAX #29 extended grapheme cluster: эмодзи ZWJ, флаги, составные смайлы могут давать отличающиеся значения. Метрика всегда отмечена `NOT_UAX29_GRAPHEMES`, её нельзя называть точным количеством графем.

## 3. A3 — орфографические повторы

Буквенные n-граммы строятся **внутри каждого русского токена** после NFC/casefold; последовательности не пересекают границы слов или дефисы, сочетания с диакритиками пропускаются. Для n=2,3:

- `letter_{n}gram_repeat_types` = число **различных** n-грамм, у которых общая частота во всём документе больше 1.
- `letter_{n}gram_excess_occurrences` = \(\sum_{g: f_g>1}(f_g-1)\).
- Пример: `мама мама` → для 2-грамм типы `ма`, `ам`; `repeat_types=2`, `excess_occurrences=4`. В опубликованном отчёте сами сочетания не выводятся.

Прокси по первым буквам:
- Окно = 5 **последовательных русских токенов**; количество окон \(W=\max(0,N_{ru}-5+1)\).
- `onset_window_count=W`.
- `onset_repetition_window_count` = число окон, где хотя бы два токена начинаются с одинаковой **буквы**.
- Это **не доказательство звуковой аллитерации**; маркируется `ORTHOGRAPHIC_NOT_PHONETIC`.

## 4. A4 — орфографические слоги

Для каждого русского токена слогоподобный показатель = число букв из `аеёиоуыэюя`. Слова без гласных (например, `в`) дают **0**, а не пропускаются.

- `russian_orthographic_syllable_total = sum(s_i)`.
- `russian_zero_vowel_token_count` = число русских токенов, в которых `s_i=0`.
- `russian_syllables_per_token_mean` = \(\mathrm{round}(\sum s_i/N_{ru}, 8)\); `russian_syllables_per_token_median` = медиана.
- Если \(N_{ru}=0\), mean/median `unavailable` и `null`, суммы/счётчики остаются равны 0.

Это **не** расстановка ударений, фонетическое деление на слоги и не расчёт ритмов речи.

## 5. A6 — лексика по словоформам

Только русские токены; после `casefold` **без** лемматизации (`ел` и `ела` — разные словоформы):

- `russian_wordform_type_count=V` = количество уникальных словоформ.
- `russian_hapax_type_count` = количество словоформ с частотой ровно 1.
- `russian_repeated_wordform_type_count` = количество словоформ с частотой больше 1.
- `russian_repeated_wordform_excess=N_ru-V`.
- `russian_max_wordform_frequency` = максимальная частота словоформы, 0 для пустого корпуса.
- `russian_ttr = round(V/N_ru, 8)` при `N_ru>0`, иначе `null/unavailable`.

**TTR зависит от длины.** При сравнении текстов с разным `N_ru` эта метрика пропускается из дельт и добавляется предупреждение `INCOMPARABLE_TTR_DIFFERENT_LENGTHS`. Это не оценка качества текста.

## 6. A7 — композиционное сечение

`golden_section_token_index = clamp(round(0.61803398875 * N), 1, N)` — 1-based индекс **общего** буквенного токена (все письменности), при \(N>0\). `round` — стандартное Python округление ties-to-even; для пустого текста возвращается `unavailable/null`. Нет выделения слов, координат источника и семантической кульминации.

Метка `NO_PSYCHOLOGICAL_EFFECT_INFERRED` напоминает: положение сечения **не измеряет силу убеждения**, скрытое воздействие, конверсию или «программирование читателя».

## 7. Сопоставление в compare

- `before` и `after` считаются одинаковым алгоритмом/методом/версией и без сторонних словарей; несовместимые по статусу, методу, версии или датасету показатели **исключаются**, а не заполняются нулями.
- Для сопоставимых чисел `delta = after - before` (дробная часть округлена до 8 знаков); все величины выводятся с `unit`, `method_id`, `method_version`, `dataset_id`, `n_before`, `n_after`.
- `compare(x,x)` обеспечивает **все числовые дельты 0**, при этом исторические и морфологические метрики не включаются, поскольку недоступны.
- `russian_ttr` с разными знаменателями не сравнивается; прочие нормированные показатели требуют осторожного чтения, особенно для коротких/разножанровых текстов.
- Статус `completed` означает, что **хотя бы одно воспроизводимое измерение сопоставлено**, но не означает полного фоносемантического анализа.

## 8. Не реализовано / источник должен быть подтверждён отдельно

`norm_letter_deviation`: нет проверенного/лицензированного нормативного корпуса (Issue #5). `pos_distribution`: морфология (Issue #6). `historical_suggestive_score`: оригинальный закрытый алгоритм, его соответствие не подтверждено (исследовательский этап #11). Все: `unavailable/null`.

`source_policy.raw_text_in_report=false` — отчёт не содержит исходную строку и словарь словоформ, но **метаданные и агрегаты всё равно потенциально информативны**. Для действительно чувствительных текстов не публикуйте отчёты без согласования.

## 9. Дополнительные редакторские индикаторы v0.7 (не исторические шкалы)

Все метрики ниже — `status=reproducible` только для **правил подсчёта**, а **не** для психологической интерпретации. Реализация `slovodel_core/editorial_metrics.py`. Для каждого индикатора сохраняется контракт `id,value,unit,status,method_id,method_version,dataset_id,n,warnings`.

| ID | Точное определение | Ограничение |
|---|---|---|
| `a4_words_3plus_vowels_count` | Количество русских токенов минимум с 3 гласными буквами | Не счёт фонетических слогов |
| `a4_words_with_vowels_count` | Число русских токенов хотя бы с 1 гласной | Явный знаменатель для следующего показателя |
| `a4_vowels_per_nonzero_word_mean` | `sum(vowels_per_token)/count(tokens_with_vowels)`, 8 знаков | Отличается от исторического A4, **не** исправленный «Диатон»; при нулевом знаменателе `unavailable/null` |
| `a7_sentence_count_by_segmentation` | Количество ненулевых предложений по существующей пунктуационной эвристике | Аббревиатуры/кавычки/поэзия могут дать другие границы |
| `a7_max_sentence_length_tokens` | Максимальное число токенов в одном таком предложении | Не абсолютный показатель удобочитаемости |
| `a7_sentences_over_25_tokens` | Предложения с более чем 25 буквенными токенами | Порог — подсказка редактору, не научная граница качества |
| `a7_golden_section_sentence_ordinal` | 1-based номер предложения вокруг `round(0.61803398875*N)` в общем списке токенов | Геометрическое положение, не смысловая кульминация Черепановой |
| `a7_golden_section_sentence_length_tokens` | Количество токенов этого предложения | Эвристика границ и сокращений |
| `a9_final_voiced_letter_review_candidates` | Число русских токенов с конечными `б/в/г/д/ж/з` (возможен `ь`), **кроме предлогов** `в, из, без, под, над, перед, об, через, из-за, из-под` и их форм на `-о` (с 0.8.0) | Только **написание-кандидат для проверки произношения**, не IPA и не фактически измеренные фонемы |

**Совместимость:** существующие показатели `russian_syllables_per_token_mean`, `golden_section_token_index` и все исторические `unavailable/null` остаются без переименования. Старые тесты и отчёты сравниваются по совпадающим методам/версиям; при новой версии Core нельзя объявлять прежние числовые результаты «исторически подтверждёнными».

**Эталоны:** [короткие опубликованные примеры](https://github.com/rubigotrafikcash-gif/slovodel/blob/main/evals/primary-v07.json), [проверочный скрипт](https://github.com/rubigotrafikcash-gif/slovodel/blob/main/scripts/benchmark_v07.py). Полные фрагменты книг и частотные таблицы не копируются.

## 10. Изменения метода 0.8.0 (Issue #24) — не тихие

Все показатели теперь имеют `method_version: 0.8.0`; `compare` сопоставляет только одинаковые версии, поэтому отчёты 0.5.0 и 0.8.0 не смешиваются.

| Что изменилось | Почему | Влияние |
|---|---|---|
| Перевод строки — граница предложения, если следующая строка начинается не со строчной буквы (заглавная, цифра, маркер списка, эмодзи, пустая строка) | Посты и списки без точек считались одним предложением | `sentence_count`, все `a7_*` по предложениям |
| `т. д.`, `т. п.`, `др.` завершают предложение перед заглавной буквой или в конце текста | «и др. Звоните» склеивало два предложения | то же |
| Невидимые символы внутри слова удаляются, апостроф между буквами склеивает | Мягкий перенос и zero-width делили слово на два | все A1/A3/A4/A6 |
| Латинские двойники в русских словах читаются как русские | Такие слова молча выпадали из русских метрик | все русские метрики |
| A9 не считает предлоги | «в доме из бумаги» давало ложных кандидатов | `a9_*` |

Новые показатели (`a1.script_hygiene`):

| ID | Определение |
|---|---|
| `invisible_format_char_count` | Число символов категории Unicode `Cf` во всём NFC-тексте (до удаления) |
| `mixed_script_token_count` | Токены, где есть и кириллица, и латиница |
| `homoglyph_folded_token_count` | Из них прочитанные как русские (все латинские буквы — двойники) |

При ненулевых значениях отчёт `audit` добавляет `MIXED_SCRIPT_TOKENS_PRESENT` или `INVISIBLE_FORMAT_CHARACTERS_PRESENT`. Перенос строки в обычном абзаце, начатый с заглавной (имя собственное), будет ошибочно считаться границей — это известное ограничение эвристики.
