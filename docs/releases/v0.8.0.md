# СловоДел v0.8.0 — надёжная проверка фактов и метрики для постов

**PUBLIC PRE-RELEASE.** Самостоятельный публичный Agent Skill. Не оригинальная программа «Диатон» и не воспроизведение исторических шкал Журавлёва или Черепановой.

Выпуск исправляет всё, что нашёл независимый аудит v0.7.0 ([Issue #24](https://github.com/rubigotrafikcash-gif/slovodel/issues/24)).

## Проверка фактов A8 rules 2.0

- **Ловит то, что раньше пропускал:** числа словами («три дня» → «пять дней»), перестановку цен и сроков между услугами, слитное «не-» («возможен» → «невозможен»), антонимы («бесплатно» ↔ «платно», «можно» ↔ «нельзя»), «может» → «должен», добавленные или удалённые гарантии, промокоды и модели с цифрами, одиночные фамилии, города, бренды на латинице, дни недели и месяцы.
- **Не мешает переписывать:** слова-условия («если», «только», «после») и охвата («все», «большинство») теперь дают находку уровня `review` — агент сверяет их сам, но текст не блокируется. Реальные изменения фактов по-прежнему `blocked` (код 5).
- **Синтетический набор:** 21 из 21 искажения заблокировано, 3 из 3 изменений охвата отмечены `review`, ни один из 18 смыслосохраняющих перефразов не заблокирован (в v0.7 на похожем наборе: поймано 4 из 20 искажений, ложно заблокировано 3 из 6 перефразов).
- **Скорость:** алгоритм линейный; худший найденный вход (1 МиБ почти из одних чисел) — около 3 с, обычный текст 1,5–2 с, вместо 29–152 с. *Обновлено 16.10.2026 без смены версии: первая сборка v0.8.0 давала 6,4 с на таком входе; поиск числительных заменён на словарь ([PR #27](https://github.com/rubigotrafikcash-gif/slovodel/pull/27)), результаты проверки фактов не изменились.*
- `guard_version: a8-rules-2.0`, схема `fact-guard.schema.json` допускает `severity: review`.

## Метрики 0.8.0 (изменение метода описано, не тихое)

- Посты и списки без точек делятся на предложения по строкам; «и др. Звоните» — два предложения.
- Мягкий перенос и невидимые символы не режут слова; апостроф склеивает имена.
- Латинские буквы-двойники внутри русских слов читаются как русские; новые показатели `mixed_script_token_count`, `homoglyph_folded_token_count`, `invisible_format_char_count` и предупреждения в отчёте.
- A9 не считает предлоги «в, из, под, без…» кандидатами на оглушение.
- `method_version` всех показателей — `0.8.0`; `compare` не смешивает его с отчётами 0.5.0.

## Windows

JSON в stdout всегда в UTF-8 — команды больше не падают с `OUTPUT_WRITE_FAILED` на английской кодовой странице консоли. CI теперь гоняет Linux, Windows и macOS на Python 3.10 и 3.12.

## Журавлёв: настоящие тесты вместо проверки на `null`

- Экспериментальный `scripts/zhuravlev.py` считает опубликованную арифметику (простое среднее, среднее распределения ответов, взвешенная оценка с весами ×4 первого звука, ×2 ударного и `p_max/p_i`) **на оценках и частотах пользователя**. Таблиц звукобукв в пакете нет. Результат всегда `status: experimental`.
- `scripts/benchmark_v08.py` сверяет её с напечатанными примерами: звук Д по шкале «сильный — слабый» = 2,0; «лик» простое среднее 2,4; «храп» 3,0; «храп» взвешенная 110,92 / 29,22 = 3,8. Для взвешенного «лик» веса 7,04 / 4 / 1 и суммы 24,78 / 12,04 совпадают с книгой, но результат 2,058 напечатан как 2,0 (совпадает только при отсечении) — расхождение записано, не скрыто.
- Источник: сетевая публикация книги автором, https://proza.ru/2023/06/04/53.
- В основном анализе исторический балл по-прежнему `unavailable/null`.

## Установка

Скачайте `slovodel-v0.8.0.zip` из этого выпуска и скопируйте **один каталог `slovodel/`**: Codex — `~/.agents/skills/slovodel/`, Claude Code — `~/.claude/skills/slovodel/`. В Claude.ai удалите старую версию навыка и загрузите архив через Customize → Skills, затем начните новый чат. Подробнее — [руководство](https://github.com/rubigotrafikcash-gif/slovodel/blob/v0.8.0/skills/slovodel/references/install.md).
