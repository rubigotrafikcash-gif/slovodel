# «СловоДел» v0.6.0 — первый публичный pre-release

**Тип выпуска:** PRE-RELEASE (ранний общедоступный релиз). **Проект:** `rubigotrafikcash-gif/slovodel`; содержимое поставки — только папка `slovodel/` с валидным `SKILL.md`. Независимые испытания AI-агента после фактической установки в Codex/Claude **ещё не завершены**, поэтому этот выпуск **не позиционируется как стабильный/проверенный кросс-клиентский релиз**.

## Что реально входит

- Файлы навыка, методика, форматы, правила редактуры и примеры, справочники лицензий, локальный Python Core **v0.6.0**, скрипты и **все пять** JSON Schema Draft 2020-12.
- `audit`: качественная диагностика, без правки оригинала.
- `rewrite`: текст редактирует AI-агент, Python сравнивает орфографические метрики до/после и эвристически блокирует изменившиеся защищённые факты.
- `create`: агент готовит текст по брифу без выдуманных функций/гарантий, Core может измерить уже подготовленный черновик.
- `compare`: действительные сопоставимые числовые дельты и отдельная проверка расхождений A8.
- Работа с русским текстом **без Python** остаётся инструкционной качественной редактурой: никаких заявлений о рассчитанных процентах, если исполняемый код не запускался.
- При Python 3.10+ Core использует только стандартную библиотеку; морфология A5 **опциональна** и требует отдельно установленного `pymorphy3==2.0.6` и `pymorphy3-dicts-ru==2.4.417150.4580142`.

## Что не включено и не доказано

- Нет оригинального «Диатона», исторических матриц и шкал «силы внушения» или общей лицензированной нормы русского языка. Исторические показатели по умолчанию `unavailable/null`.
- A8 **не доказывает смысловую или юридическую эквивалентность**, не разрешает самостоятельную публикацию (`publication_ready=false`).
- Нет собственного сервера, API, MCP, n8n, VPN, Telegram-бота, хранения чужих текстов или внешнего AI-генератора.
- **Реальные E2E-запуски установленного навыка в аутентифицированных Codex/Claude/Gemini — NOT_RUN**. Подтверждены только структура и Python CLI из изолированного каталога навыка, плюс прежний CI; тесты без Python проводятся как анализ инструкции, а не фактический ответ внешнего агента.
- Лицензия собственных файлов — MIT. Опциональный русский словарь имеет **отдельную лицензию CC BY-SA 3.0**; пользователь должен соблюдать её условия.

## Как установить

Скачай архив **`slovodel-v0.6.0.zip`** из assets этой страницы (в нём **один корневой каталог `slovodel/`**) либо клонируй tag `v0.6.0` и скопируй папку `skills/slovodel/`.

Для Codex: `~/.agents/skills/slovodel/`. Для Claude Code: `~/.claude/skills/slovodel/`. Полное руководство Linux/macOS/PowerShell, установка без Python, удаление и команды проверки — [references/install.md](https://github.com/rubigotrafikcash-gif/slovodel/blob/v0.6.0/skills/slovodel/references/install.md).
