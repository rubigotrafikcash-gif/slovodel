# СловоДел v0.7.0 — предварительная версия AI-копирайтера для текстов на русском языке

**PUBLIC PRE-RELEASE.** Это დამოუკიდимое развитие публичного Agent Skill, а **не** оригинальная программа «Диатон» и не воспроизведение исторических фонетических шкал Черепановой или Журавлёва.

## Что новое

- `SKILL.md` ориентирован на задачи копирайтера: писать и улучшать **тексты на русском языке** для постов, сайтов, рекламы, рассылок, интерфейсов и сценариев. По умолчанию выдавай готовый результат и только необходимые пояснения — без длинных машинных отчётов.
- A4: `a4_vowels_per_nonzero_word_mean` с отдельным знаменателем, `a4_words_with_vowels_count`, `a4_words_3plus_vowels_count`. Старые A4-метрики **не переименованы и не подогнаны** под пример.
- A7: `a7_golden_section_sentence_ordinal`, `a7_golden_section_sentence_length_tokens`, `a7_max_sentence_length_tokens`, `a7_sentences_over_25_tokens`; индексы помогают редактору, но не устанавливают смысловую кульминацию или эффект воздействия.
- A9: `a9_final_voiced_letter_review_candidates` указывает только русские слова с графическими признаками, потенциально требующими проверки конечного оглушения при озвучке. **НЕ** транскрипция IPA, не полный фонетический анализ, не шкала воздействия.
- Оригинальные A1–A8, A2 с ненормативным локальным профилем и опциональная морфология сохранены. Числа автоматически не подтверждают публикацию, факты/авторский голос остаются приоритетом.

## Тестирование на первоисточниках

- `scripts/benchmark_v07.py` действительно вызывает Python Core 0.7 для **10 опубликованных слово-шкальных примеров Журавлёва**, соответствующих восьми словам: «лик», «храп», «урщух», «лимень», «манаф», «хифель» (три шкалы), «фрыш», «незич».
- Дополнительно **сравниваются две реально опубликованные пары Журавлёва**: «храп» → «прах» (перестановка звуков) и «хилый» → «милый» (замена первого звука). Оба сравнения дают 0 изменения длины и среднего числа орфографических слогов; это показывает, почему такие метрики не заменяют фоносемантические оценки.
- Также скрипт вызывает Core на **двух коротких опубликованных фрагментах Черепановой**: «В деле смелая» и «Пространство и время окружают его целями, но он определяет главные». Это *короткие фрагменты*, **не** полный воспроизводимый эксперимент оригинальной программы.
- Исторические оценки Журавлёва (2.0, 3.8 и др.) и оценки текста Черепановой **не вычисляются** текущим Core. Поэтому `historical_value_difference=null` и `historical_algorithm_similarity_percent=null`, а не ноль и не выдуманный процент совпадения.
- Шесть полных текстов Черепановой представлены **только как опубликованные эталоны и ранее полученный v0.6 аудит**: `v07_full_text_reexecution=NOT_RUN`. Точные входные тексты не включены в открытый репозиторий; копировать их без прав и выдавать чужой эталон за новый v0.7 результат нельзя.
- Источник: А. П. Журавлёв, *Звук и смысл* (1991), https://ru.scribd.com/document/735405357/; И. Ю. Черепанова, *Заговор народа* (2002), https://ru.scribd.com/document/937681099/; Т. М. Рогожникова (2025), https://psyjournals.ru/journals/langt/archive/2025_n4/Rogozhnikova.

## Установка

Загрузить asset `slovodel-v0.7.0.zip` из этого GitHub Release, затем скопировать **один каталог `slovodel/`**:
- Codex: `~/.agents/skills/slovodel/`
- Claude Code: `~/.claude/skills/slovodel/`

Путь установки, PowerShell, обновление и удаление — [руководство](https://github.com/rubigotrafikcash-gif/slovodel/blob/v0.7.0/skills/slovodel/references/install.md). Для основных измерений требуется Python 3.10+, без Python остаётся только качественная AI-редактура. В самом Core нет удалённых запросов, API или серверной инфраструктуры.

## Правовые и научные ограничения

Общие лингвистические идеи доступны для независимой проверки, но это не означает наличия лицензии на чужие таблицы 46×25, ПО, полный закрытый набор данных или саму историческую марку. Не распространять в публичной папке чужие корпуса и тексты без основания. Нет доказательств воздействия на нейроны, подсознание, запоминаемость или конверсию.

**Статус тестов:** смотреть GitHub Actions по версии и commit SHA; наличие кода или этого документа само по себе не подтверждает прохождение CI. Реальное E2E в авторизованных клиентах Codex и Claude Code всё ещё `NOT_RUN`, проверена только исполняемая переносимость Python каталога навыка.
