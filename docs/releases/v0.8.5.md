# v0.8.5 — STABLE

Стабильный выпуск публичного навыка и локального Python Core. Русская редактура
и опубликованная методология Черепановой/Журавлёва сохранены. Профиль бренда
необязателен. Исторические фоносемантические шкалы не выдаются за выполненные
измерения.

Выпуск включает исправления 0.8.3–0.8.5:

- сохранение модальности, исторического времени, атрибуции, диапазонов и единиц;
- проверку условий выбранного продавца, точности замечаний и объёма текста;
- `check_workflow.py`: реальные коды Core, хеши, структура и честный статус схем;
- Windows-запускатель, проверку Python 3.10+ и прямой резервный запуск при ошибке
  инструмента runtime или запрете PS1 без изменения настроек системы;
- запись фактического Python и его версии в журнал исполнения.

Core требует доступных файлов и разрешённого исполнения. Без него сохраняется
качественная работа агента. `draft_requires_review` не является ошибкой и не
разрешает автоматическую публикацию. Смысловую сверку агент завершает сам.
`jsonschema` и морфологический словарь остаются необязательными; недоступность
измерений и полной проверки схем обозначается явно.

Архив содержит одну автономную папку `slovodel/`. Установленный аккаунтный
плагин обновляется отдельно с сохранением идентификатора. Точные результаты
заключительного прогона и ограничения — в
[протоколе готовности](../V085_RELEASE_READINESS.md).
