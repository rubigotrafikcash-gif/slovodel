## 3. Где проверялось и чего ещё нет

**Проверено:** копирование каталога в структуры, рекомендованные Codex и Claude Code; доступность всех инструкций/схем/скриптов внутри перенесённого каталога; реальные CLI, `audit`, `rewrite`, `create`, `compare`, блокировка защищённых сумм, прямая совместимость отчётов. Для качественного режима без Python проверено наличие инструкций/файлов, **но агент не запускался без Python**.

**НЕ ПРОВЕРЕНО:** реальное обнаружение/активация `slovodel` через `$slovodel` или `/slovodel` в аутентифицированных Codex CLI/Claude Code; ответы моделей после установки и поведение ChatGPT desktop/mobile. Здесь нет установленного Codex/Claude runtime с рабочей авторизацией для E2E. Поэтому `agent_runtime_invoked=false` и **independent-agent E2E=NOT_RUN**. Переносимость файла и оболочки не является подтверждением качества работы модели; выпуск **pre-release**. Не объявлять распространение через ChatGPT mobile или каталог Plugins — это отдельная система распространения.

**Зависимости и права:** базовый Core — только Python 3.10+ stdlib (при наличии исполнения), оригинальная редакторская часть работает без Python. Морфология `pymorphy3` (MIT) + отдельный русский словарь с **CC BY-SA 3.0**: он **не включён** в пакет. Пользовательские локальные профили A2 ненормативные; данные от третьих лиц нельзя использовать без прав. Историческая программа «Диатон», шкалы воздействия, лицензированная общерусская норма и публикационный автодопуск отсутствуют.

## 4. Тег и выпуск

Метка/tag создаётся **только после успешного merge PR #20 в `main`** через [release-v0.6.0.yml](../.github/workflows/release-v0.6.0.yml).
