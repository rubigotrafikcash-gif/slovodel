# Issue #22 — v0.7.0: пользовательский AI-копирайтер и реальные тесты по первоисточникам

**Дата работы:** 16.10.2026. **Сфера:** только публичный Agent Skill. **Текущая ветка:** `release-v0.7.0-copywriting-benchmarks`. Работа не касается приватных серверов, текстов клиентов или других продуктов.

## Реально созданные функции

- `SKILL.md`, `README.md`, `references/copywriting-ux.md`: понятное описание **«AI-копирайтер для создания и улучшения текстов на русском языке»**, простой маршрут из написания, проверки фактов, ритма, естественности и результата.
- Core `0.7.0` включает прежние A1–A8 **без тихого изменения прошлых формул** и отдельные воспроизводимые редакторские показатели `editorial_metrics.py`: уточнение знаменателя среднего числа гласных, слова с 3+ гласными, расположение геометрической точки 61,8% внутри предложения, количество длинных предложений и **графические кандидаты на проверку конечного оглушения**. Все фонетические кандидаты помечены `SPELLING_HEURISTIC_NOT_IPA`/ `NOT_A_PHONETIC_TRANSCRIPTION`. **Настоящая IPA-транскрипция и ударения не реализованы.**
- Синхронизированы внутренние версии `__version__`, `pyproject.toml`, Skill metadata.
- Появились `evals/primary-v07.json` и `scripts/benchmark_v07.py` с машинным протоколом. В раннере **реально исполняются 10 слово-шкальных примеров Журавлёва и 2 небольших текстовых фрагмента Черепановой**, сохраняются фактически посчитанные Core орфографические показатели, ID источника, метод/ограничения.

## Честное сравнение с первоисточниками

### А. Журавлёв, «Звук и смысл», 1991, с. 32–36

10 тестовых пар относятся к 8 различным словам — «лик», «храп», «урщух», «лимень», «манаф», «хифель» (3 шкалы), «фрыш», «незич». Опубликованные у Журавлёва баллы от 2.0 до 4.2 нельзя приравнивать к сумме гласных, орфографическим повторам или A9. **10/10 реальных Core запусков возвращают `historical_suggestive_score=unavailable/null`**, а не фиктивный исторический балл. Историческую процентную «точность» вычислить невозможно, поэтому `historical_algorithm_similarity_percent=null`.

Два опубликованных Журавлёвым примера изменения звукового облика слов — **«храп» → «прах»** и **«хилый» → «милый»** — теперь также вычисляются настоящим `compare()` Core v0.7. По обоим сохраняются число слов, число гласных на слово и длина, хотя автор противопоставляет их звучание. Это **проверяемая граница продукта**, а не доказательство непригодности исторической модели. Фоносемантический показатель по обеим парам — `unavailable/null`.

### Б. Черепанова, «Заговор народа», 2002, с. 81–83

Два **коротких фрагмента** первичного текста используются как допустимые ограниченные примеры того, как Core обрабатывает русский язык; **они не эквивалентны запуску полного текста** и не могут воспроизвести числовые показатели оригинального «Диатона».

Для **шести полных текстов** в `evals/primary-v07.json` есть только **прошлые результаты аудита v0.6**, поскольку все шесть полных первичных текстов вместе с точным provenance не распространяются как открытые тестовые данные и на них **НЕ** запускалась новая версия 0.7 в CI. Значения: оригинальные средние 3.45/2.45/2.33/2.64/2.10/2.03; прежние v0.6 средние по русским буквенным словам 2.40/2.35/2.20/2.58/1.98/1.90. Это **разные алгоритмы/знаменатели**. Нельзя считать 4 из 6 совпадений A7 из старого аудита доказательством корректности A7 в v0.7.

Указанные источники — цифровые копии книг, **не лицензия на копирование полного текста, кода или оценочных таблиц**. Историческое закрытое ПО не запускалось. См. [исследование Issue #11](research/ISSUE_11_SOURCE_AUDIT.md).

### В. Нет эксперимента «до → после» с одинаковыми историческими алгоритмами

Сами источники дают исторические числовые оценки слов/текстов, но **не** документированный A/B-парный эксперимент одного текста `before` / `after` с одинаковой версией ПО, лицензированными входами и настройками. Корректно сравнить эффект «после редактуры» с оригинальной программой нельзя. В v0.7 A8 продолжает проверять факты при реальной пользовательской правке; метрики Python не подтверждают качество AI-копирайтера на аудитории.

## Решение

Продвигать v0.7 как **incremental public pre-release AI-копирайтера**, но не выдавать его за воспроизведённый «Диатон» и не объявлять полноценной IPA-фонетикой. Полноценные адаптации звучания, реальные 6 полных исторических текстов, права на таблицы 46×25, A/B пользовательская оценка редактур и независимая активация навыка в авторизованном AI-клиенте требуют новой контролируемой работы.
