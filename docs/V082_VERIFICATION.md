## Реализовано

- A8 rules 2.2: осторожное сравнение смешанных кириллическо-латинских слов;
  интервалы преобразований отсылают к неизменённому локальному оригиналу.
  Чистые алфавиты, URL, email, коды с цифрами и буквальные protected terms
  не получают общего разрешения на замену.
- Числа сравниваются вместе с единицами площади/длины/объёма. Поддержана
  двухстрочная характеристика товара: название и единица, затем значение.
- Сигналы времени, неопределённости и атрибуции имеют уровень review.
  Они не являются доказательством эквивалентности. Контекст брифа сверяет агент.
- Инструкции требуют сохранять обязательный контекст, проверять грамматическое
  основание замечаний и самостоятельность устной версии. Пять уровней методологии
  сохранены; численных исторических шкал не добавлено.
- Машинная блокировка и редакторское решение учитываются отдельно. Возврат
  испорченного написания ради снятия блокировки запрещён.
- Добавлен повторяемый локальный replay с stdout, stderr, exit code, SHA-256,
  командами, временем и null для неизвестных платформенных метаданных.

## Повторный Core на зафиксированных ответах

Обработаны 106 случаев / 212 ответов. Для 86 заданий rewrite/spoken получены
172 отчёта A8 с совпадением входных/выходных хешей с прежними журналами;
все 172 соответствуют обновлённой JSON Schema. Для 20 заданий audit выполнены
40 вызовов audit: текст замечаний не рассматривается как переписанный исходник.

На сопоставимых 172 ответах: раньше 49 blocked / 123 draft_requires_review,
теперь 42 / 130. Ровно семь переходов — A01_A, A01_B, A03_A, A04_A, A04_B,
A05_A, A05_B. Это устранённые блокировки нормализации, а не семь новых ответов.
Новых блокировок на этом корпусе нет. Во время разработки обнаружены и исправлены
пять ложных сигналов перевода табличных характеристик в прозу; они включены в
синтетические контрольные тесты.

Core по-прежнему не обнаруживает все смысловые ошибки старых ответов. Числа выше
не доказывают улучшение генерации и не являются полной оценкой FP/FN.

## Воспроизведение и следующий контроль

```text
python -m unittest discover -s tests -v
python scripts/release_smoke.py --output <новый-путь>/install.json
python scripts/offline_smoke.py
python scripts/replay_audit.py --evidence <распакованный-частный-архив> --output <новая-локальная-папка>
```

Replay не создаёт новые ответы и не изменяет входной архив. Ошибки входного
хеша останавливают его до записи результатов. Не публиковать папку replay:
она содержит исходные фрагменты и тексты ответов.

До заявления об улучшении редакторского качества провести независимый
[контроль по рубрике](../evals/v082-semantic-rubric.md) с одинаковой моделью/effort,
скрытыми метками ветвей и свежими материалами. Релиз, merge и обновление
установленного плагина этим документом не подтверждаются.
