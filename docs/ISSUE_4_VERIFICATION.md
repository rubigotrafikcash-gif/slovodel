## 1. Реализовано

- A1: общий и русскоязычный буквенный токен-счёт, эвристический счёт предложений, Unicode code points, приближённые базово-диакритические кластеры (не UAX #29), раздельное число каждой из 33 русских букв, включая е/ё.
- A3: биграммы и триграммы **букв** внутри русских слов; число повторяющихся типов и повторных вхождений; 5-токенные окна с совпадением первой **буквы**.
- A4: сумма и статистика числа орфографических гласных в русских словах; слова без гласных дают 0, пустой набор даёт `null/unavailable` для среднего и медианы.
- A6: агрегаты русских словоформ, в том числе число типов, hapax, повторов, максимальная частота, TTR = V/N (только при N>0); без публикации самих словоформ.
- A7: 1-based позиция `clamp(round(0.61803398875*N), 1, N)` для общего числа буквенных токенов. Геометрическая эвристика, **не показатель воздействия на читателя**.
- `audit`: воспроизводимые `reproducible` элементы `measurements` с единицами, методами, версиями, объёмом выборки и предупреждениями.
- `compare`: только совпадающие методы/версии/датасеты, `delta = after - before`; различная длина русских текстов исключает TTR из сравнения; `compare(x,x)` даёт нулевые дельты.
- Нет нормативного корпуса (A2 — Issue #5), POS/морфологии (Issue #6), семантического fact guard (Issue #7), исторической «силы внушения» (отдельный исследовательский этап). Соответствующие значения остаются `unavailable/null`.

## 4. Известные ограничения

1. Реализован **орфографический и статистический**, а не полный фонетический/просодический или психологический анализ. Реальные звуковые значения, нормативы и «эффективность внушения» не определяются.
2. `sentence_count` — эвристика знаков `.!?…`, с ограниченным набором сокращений; не выполняется синтаксический разбор.
3. `base_mark_cluster_count` — агрегирование по категориям Unicode без реализации UAX #29, эмодзи ZWJ/flags могут считаться неточно.
4. URL и email маскируются обычными регулярными выражениями, не полным RFC-парсером; Markdown/HTML/цитаты/код не обрабатываются отдельно.
5. Нормальная форма NFC используется только на копии; карта координат исходного текста пока отсутствует.
6. TTR зависит от длины. Остальные суммарные числовые дельты могут быть несопоставимы между жанрами/объёмами без дополнительной контекстной интерпретации.
7. Данные отчёта агрегированные, но SHA-256 и малые частотные профили могут нести информацию о тексте. Не публиковать отчёты конфиденциальных материалов без согласования.
8. Нет сетевых вызовов в нашей runtime-логике, но Python сам по себе не изолирован на уровне ОС.
9. Версионный код/документы внутри публичного навыка; **никакие приватные сервисы или соседние Issues не изменялись**.
