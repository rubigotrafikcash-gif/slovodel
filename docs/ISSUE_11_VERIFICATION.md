# Issue #11 — акт источниковедческого исследования и приёмки

**Дата:** 2026-10-16. **Тип работы:** исключительно историко-методологическое исследование, без подключения закрытых программ, без Python-реализации исторической методики. **PR:** Issue #11, отдельная ветка `issue-11-historical-source-audit`.

## Цель и артефакты

1. [Полный источниковедческий отчёт](research/ISSUE_11_SOURCE_AUDIT.md) — перечень первичных/вторичных источников, подтверждённые и отсутствующие компоненты, формула Журавлёва, проверка примеров, правовые ограничения, итоговый NO-GO.
2. [Машиночитаемая матрица](research/historical-scale-matrix.json) — **56 строк:** 25 исходных шкал звукобукв/слова, 20 отдельно пронумерованных текстовых шкал **без вымышленных названий**, 11 тематических групп функций (повторная классификация, не дополнительные шкалы).
3. [Методология публичного навыка](../skills/slovodel/references/methodology.md) — обновлена исследовательская позиция, исправлен устаревший тезис «Python Core не существует».
4. [README](../README.md) — исследовательская граница открытой версии, отдельное от v0.6.0 решение `NO_GO_NUMERICAL_RELEASE`.
5. [tests/test_historical_manifest.py](../tests/test_historical_manifest.py) — автоматическая проверка структуры `25 + 20 + 11`, неизвестных имён 20 шкал, `unavailable/null` у **каждого** исторического расчёта, непридуманной лицензии, ссылок и явных числовых несоответствий.

## Подтверждения

- Прямой авторский текст Журавлёва (1991) подтверждает наличие **46 звукобукв и 25 признаковых шкал**, принцип `p_max/p_i`, первый звук `×4`, ударный `×2`, а также сравнительные иллюстрации «лик» и «храп».
- Исходник Черепановой (2002) говорит о **20 шкалах текста**, но полный список *с собственной версионной привязкой*, оригинальная калибровка и лицензированные данные в проверенных материалах не подтверждены.
- Обзор Л. П. Прокофьевой описывает ДИАТОН/ВААЛ как существовавшие инструменты и различия их версий; публикация не содержит разрешения перепечатывать ПО, таблицы или массивы эталонных текстов.
- В статье 2025 года есть некоторые готовые результаты программ, но без полной воспроизводимой цепочки «ввод, версия, параметры, таблицы, эталон», поэтому они **не** внесены в Core как числовые образцы.
- В доступных электронных копиях неоднозначное `346` разобрано как OCR-артефакт: `46 × 25 = 1150`, а не `346 × 25`.
- Иллюстративное вычисление `24.78/12.04 ≈ 2.058`, при математическом округлении на один десятичный знак `2.1`; доступный текст книги называет `2.0`. Отсутствует подтверждённое правило округления/корректировки; **не выполнять подбор, чтобы достичь «исторического совпадения»**.
- Не найдено подтверждения прав на полную историческую таблицу `46×25`, её включение в MIT-репозиторий, оригинальные данные и сам код. **Ссылка на сайт для чтения не доказывает право на перепубликацию.**

## Правило статусов

- **`reproducible`** — только полностью реализованная, проверенная на эталонах, документированная с правами формула. У исторических расчётов этой категории **нет**.
- **`experimental_candidate_unvalidated`** — опубликована математическая структура независимого метода Журавлёва и некоторые промежуточные значения; этого **не** достаточно для выпуска нового вычислителя.
- **`unavailable/null`** — реальный runtime-статус **у всех 56 позиций матрицы**, в том числе 25 именованных, 20 неназванных текстовых и 11 групп. `0` нигде не подставляется за отсутствующие данные.

## Принятое решение

**NO_GO_NUMERICAL_RELEASE.** Исследование завершено при фактически недостаточных исходных данных/правах/версионированных тестах. Нельзя объявлять совпадение с «Диатоном», вычислять силу внушения, прогнозировать реакции или делать утверждения о ритмах мозга. **Никаких вычислительных функций не добавлять по данной Issue.** Новая независимая экспериментальная реализация только после **отдельной согласованной GitHub Issue** и проверки источников, лицензий, фонетического слоя и референтных тестов.

## Приёмочные проверки CI

Фактические результаты последнего CI, точный SHA PR и ссылка на PR добавляются в финальное описание Issue #11 **после завершения GitHub Actions** и перед закрытием задачи. Ожидаемые тесты: прежние 160 + 5 проверок исследовательского манифеста. **Наличие этого ожидаемого числа не является утверждением об успешном прогоне.** Поскольку изменений в историческом Core нет, публичный pre-release `v0.6.0` остаётся неизменным.

**Граница проекта:** только публичный GitHub-навык. Частные MCP/API, VPS, n8n, Wirebot, домашние серверы и пользовательские исходные тексты не затрагиваются.
