# СловоДел Public — техническая спецификация v1.0 (baseline)

Дата: 2026-10-15. Основание: [утверждённые границы](PROJECT_DECISIONS.md), аудит текущей ветки `main` на `14858891e7235953ec93e88001dcf8bcf1fb3758`, исходная [методология](../skills/slovodel/references/methodology.md). **Это спецификация будущих работ; функциональность не считается реализованной.**

## 1. Цель / исключения

**Цель:** открытый, работающий без собственного сервера русскоязычный Agent Skill, который:
1. Сохраняет прежние сценарии редактуры (посты, статьи, сайты, UI, боты, видео и т. д.).
2. При поддерживаемом локальном Python даёт воспроизводимые лингвистические измерения из строго определённого инструментария.
3. Предоставляет режимы `audit`, `rewrite`, `create`, `compare`; при отсутствии интерпретатора честно ограничивается качественной оценкой.
4. В каждом варианте сохраняет исходные факты и позволяет установить происхождение конкретных чисел/методов.

**Не входит в текущий объём:** частный MCP/REST/API, n8n, VPS, Wirebot/домашний сервер, онлайн-сервис, платные провайдеры, личная история, аккаунты пользователей, автоматическая публикация. Не копировать оригинальную программу «Диатон»/«Словодел» и не обещать совпадения её чисел.

## 2. Источниковедческое разграничение

Программа Черепановой описана историческими авторами на пяти уровнях (фонологический, просодический, лексико-стилистический, лексико-грамматический, морфо-синтаксический). Перечисляются девять групп: фонетические значения, звукоцвет, повторы и частоты, «высокие/низкие» звуки, слоги, композиция/«золотое сечение», лексико-стилистические индексы, грамматический состав, внутренний частотный словарь. Сведения о 25 признаках анализа **слова** и 20 шкалах анализа **текста** не являются взаимозаменяемыми. Публично недоступные настройки и калибровки не реконструировать произвольно.

Статусы:
- `reproducible`: опубликованный и реализованный алгоритм + версии и тесты;
- `qualitative`: суждение AI/редактора, не числовая оценка;
- `experimental`: исследовательская реконструкция с ограничениями и источником, выключена по умолчанию;
- `unavailable`: данные/права/формулы отсутствуют; значение `null` и причина.

Запрещены фиктивные баллы внушения, «ритмы мозга читателя», детектор лжи, прогноз конверсии по звукобуквам и выдача приближённого результата за оригинальное ПО.

## 3. Режимы и конвейер

| Режим | Вход | Выход | Особые условия |
|---|---|---|---|
| `audit` | Один текст | Измерения, редакторская оценка, неизвестное, рекомендации | Исходник не переписывать |
| `rewrite` | Исходник + цель | Исправленный текст + «Что изменено» + проверка фактов + повторные измерения при доступном движке | Изменения критичных фактов блокируют выдачу без подтверждения |
| `create` | Бриф, факты, формат | Черновик + проверка + недостающие факты | Не придумывать числа, цены, функции, отзывы, гарантии |
| `compare` | Два текста | Сопоставимые показатели и дельты + смысловые различия | Только при одинаковом методе, настройках, версиях и корпусах |
| `historical_research` | Вопрос о методике | Отдельная справка по источникам и ограничениям | Не выдавать несуществующий расчёт |

Конвейер: неизменяемый исходный UTF-8 текст → Unicode NFC на копии + карта позиций → сегментация → измерения → AI-редактор (если запрошен) → проверка защищённых фактов → повторные измерения → отчёт. Исключения/обработка URL, числа, латиницы, эмодзи, кода и разметки должны явно документироваться.

## 4. Вычислительные функции

**A1 — токены и графемы.** Слова, предложения, русские буквы, отдельные `е/ё`, распределения, знаменатели, Unicode NFC/NFD. Зафиксировать правила для тире, дефисов, сокращений, цифр и смешанного письма.

**A2 — частотные отклонения.** Вычислять только относительно легально доступного, версионированного и документированного нормативного корпуса `q_i`: `delta_pp = 100*(n_i/N - q_i)`, `ratio = (n_i/N)/q_i` при `q_i>0`. Пока подходящего корпуса нет — `unavailable`. Для коротких текстов выдавать предупреждение о ненадёжности интерпретации; статистическую значимость не назначать без модели и поправок.

**A3 — повторы.** Подсчитывать буквенные повторы, n-граммы, окна, повторяющиеся словоформы. Не называть буквенные повторы фонемными без подтверждённого модуля транскрипции.

**A4 — слоги.** Базовый орфографический показатель: количество русских гласных `аеёиоуыэюя` в слове, с явными правилами исключений и неопределённости. Среднее, медиана, распределения. Не равнять автоматический подсчёт слогов полной просодии.

**A5 — морфология.** Доли частей речи по версионированной модели/словарю; указание морфологической неоднозначности. Внешняя зависимость допустима только после юридической и воспроизводимой проверки; библиотека сама по себе не гарантирует контекстное разрешение омонимии.

**A6 — лексические показатели.** Употребления `N`, типы `V`, `TTR=V/N` (при `N>0`), hapax, частотные списки. Обозначить, используются ли леммы или словоформы. Для разных длин предупреждать о несопоставимости TTR. Не выдавать за недоступные исторические индексы.

**A7 — композиция.** Позиция условного сечения `round(0.61803398875*N)` с явной единицей `token|grapheme`, маппингом на исходник и оговоркой, что это композиционная эвристика, **не измерение психологического воздействия**. Смысловую кульминацию аннотирует редактор.

**A8 — защита фактов.** Сопоставление ссылок, сумм, дат, чисел, диапазонов, сущностей, обязательных условий и существенных отрицаний. Детерминированная часть — строгая; семантический риск — отдельно с пометкой «нужна проверка». Утрата защищённого факта возвращает `blocked`/требует согласования.

### Исследовательский пакет B (только отдельный условный этап)

- **B1 Журавлёв:** независимая реализация опубликованной взвешенной оценки звукобукв по шкалам **только после** проверки всей матрицы, частот, ударений, точных формул и прав на воспроизведение. Не объявлять «результатом Диатона».
- **B2 Черепанова:** её исторические текстовые шкалы и агрегацию не воспроизводить без достаточного открытого алгоритма.
- **B3 звукоцвет / высокие-низкие звуки / мягкое-жёсткое кодирование:** `unavailable` по умолчанию.
- **B4 индексы Мистрика / словарь «творческого бессознательного»:** не придумывать формулы или внутренний словарь программы.
- **B5 воздействие на мозг / ложь / здоровье / прогноз поведения:** исключено.

## 6. Контракт JSON и отчёта

У каждого измерения: `id`, `value`, `unit`, `status`, `method_id`, `method_version`, `dataset_id` (или `null`), `n`, `warnings`; для всего отчёта: `schema_version`, `source_sha256`, `language`, `mode`, `tool_version`, `source_policy`, `errors`.

Пример структуры (**не реальный результат запуска**):
```json
{
  "schema_version": "1.0.0",
  "mode": "audit",
  "language": "ru",
  "source_sha256": "<sha256>",
  "measurements": [
    {
      "id": "historical_suggestive_score",
      "value": null,
      "unit": null,
      "status": "unavailable",
      "method_id": null,
      "method_version": null,
      "dataset_id": null,
      "n": null,
      "warnings": ["Алгоритм оригинальной программы не опубликован полностью"]
    }
  ],
  "historical_compatibility": "not_verified"
}
```

В user-facing выдаче чётко разделять: **«Измерено» / «Редакторская оценка» / «Не определено»**. Для `rewrite` дополнительно: готовый вариант, до трёх существенных правок, список блокирующих вопросов. Никогда не выдумывать числа при отсутствии инструмента.

## 7. Тестирование и критерии качества

- Все алгоритмы имеют документированные правила, тесты на обычные и граничные значения; детерминированный Core ≥90% line coverage (цель, а не текущее состояние); ключевые сценарии `blocked`/`unavailable` покрыты специально.
- Пустой текст, Unicode NFC/NFD, `е/ё`, смешанная латиница, дефисы, кавычки, URL, суммы, даты, слова с неоднозначным ударением, аббревиатуры, длинные тексты и случаи потери отрицания — обязательные фикстуры.
- `audit`: исходник байтово неизменен.
- `compare(x,x)`: все сопоставимые дельты нулевые.
- Нельзя сравнивать разные версии алгоритма/корпуса без явного предупреждения или отказа.
- Нет корпуса / неизвестно ударение / нет лицензированных исторических таблиц → `null` + `unavailable`, не фиктивное число.
- При изменении защищённых фактов `rewrite` не помечается безопасным.
- `evals/cases.md` содержит 17 исходных сценариев; исправить противоречие теста гарантии с `compliance.md` и недостаточные входные данные некоторых сценариев, расширить тесты на анализ без переписывания и ошибочные числовые оценки.
- В CI: unit, schema, package/install smoke, no-network smoke, manual agent-evals documented. Сообщаем реальные результаты, не используем заявленные 171/200 из старого PR как проверенный KPI.
- Важные изменения — отдельный PR и review. Merge и закрытие Issue только после прохождения acceptance criteria.

## 9. Критерий релиза публичной версии

Установленный каталог навыка обеспечивает качественную редактуру даже без Python; при локальном исполнении CLI даёт воспроизводимые результаты и версии расчётов; соблюдается контроль защищённых фактов; данные пользователя не отправляются наружу; опубликованы инструкции, лицензии, тесты и ограничения. Недоступные исторические параметры всегда описаны честно.
