## Готовность к выпуску

Перечисленные семь сигналов разобраны, целевые исправления и локальные проверки
завершены. Кандидат предназначен для редакторской работы с проверкой человеком.
Сложные неподдержанные числительные, произвольные склонения имён, неоднозначные
даты и смысловые связи остаются консервативными сигналами. Отсутствие блокировки
не доказывает фактической правильности. Перед публикацией версии требуется
проверить статус GitHub Actions конкретного коммита; сам выпуск этим файлом
не подтверждается. Полные частные тексты и журналы не включены в репозиторий.
