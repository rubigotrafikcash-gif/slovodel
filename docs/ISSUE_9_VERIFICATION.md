**Ограничение:** 18 репетиций выполнены текущим ассистентом, который видел SKILL как текст и сам себя оценивал. Это **не** независимые прогоны навыка, установленного в Codex CLI, Claude Code или Gemini CLI. У независимых клиентов статус **NOT_RUN**; не следует делать вывод «18/18 внешних агентских тестов PASS» или объявлять полную кросс-клиентскую проверку завершённой. Текущие данные достаточны для воспроизводимости Python Core и предварительной редакторской самооценки; независимый agent acceptance остаётся условием окончательного публичного релиза.

## 4. CI, негативные результаты и их исправление

- При первой модификации GitHub workflow не запускал ни одного задания: его имя содержало необрамлённое кавычками двоеточие (`name: ...: ...`) — синтаксическая ошибка YAML. Исправлено; после этого workflow создаёт задания на **Python 3.10 и 3.12**.
- При добавлении машинной проверки журнала агентских ответов тестовый шаблон регулярного выражения был неверно экранирован; исправлены выражение и ожидаемый счётчик. Ошибочный промежуточный CI не учитывался как PASS.
- После исправлений CI подтверждён реальными логами: **160 тестов**, coverage **97%**, защита от сетевых вызовов **PASS**.
- `coverage==7.10.7` используется как версия инструмента только в CI; Python Core не получает runtime-зависимость coverage.
- [scripts/offline_smoke.py](../scripts/offline_smoke.py) и тесты выключают обычные Python socket/connect/getaddrinfo/urllib при выполнении синтетических сценариев. Это проверяемый **smoke**, но не изоляция от сети на уровне ОС, не полный доказанный запрет всех способов выхода в интернет.
- Приватные пользовательские тексты, авторизации, токены и реальные каналы в фикстуры не добавлены. Только искусственные предложения, `example.org`, демонстрационные имена и суммы.

## 5. Технические и релизные границы

1. Покрытие 97% не равно «97% правильности текста»; машинные лингвистические эвристики и A8 могут давать ложные предупреждения и пропуски.
2. Не появился лицензированный общерусский нормативный корпус; `norm_letter_deviation=unavailable/null`.
3. Программа Черепановой/«Диатон», её исторические шкалы и прогнозы «силы внушения» не воспроизводятся и не выдаются за измерения.
4. Не выполнены независимые агентские прогоны с реально установленным скиллом; публичный выпуск в конкретном AI-клиенте **не считается подтверждённым** только на основании этой Issue.
5. Текущий CI — GitHub Actions с онлайн-установкой dev-зависимостей; собственный **runtime** не имеет проектных сетевых вызовов. Это разные утверждения.
6. Изменений в приватной инфраструктуре, n8n, VPS, домашнем сервере и проектных клиентских публикациях нет.
