# Границы и критерии выпуска 0.8.5

Проверяется надёжность поставки и редакторского workflow. Проект не строит
новую модель русского языка, не заменяет словари и не обещает безошибочную
редактуру произвольных текстов.

Фиксированный протокол перед публикацией:

1. Прямая проба Python без PS1 в системном Windows PowerShell; четыре режима,
   сохранение кода 5, честный отказ при недоступном интерпретаторе.
2. Модульные и интеграционные тесты, автономная установка, офлайн-проверка,
   полные схемы и CI Linux/Windows/macOS, Python 3.10/3.12.
3. Восемь новых временных сеансов Codex CLI: create/rewrite/audit/compare,
   каждый с явным и неявным вызовом. Модель gpt-6.1-sol, effort medium;
   серверный snapshot неизвестен. Одна исходная попытка на условие, все
   продолжения сохраняются отдельно и не подменяют результат неявного вызова.
4. Проверка прочитанного кандидата 0.8.5, реального Core, режима, кода,
   файловых хешей, целостности исходников и редакторского результата.
5. После прохождения — merge, стабильный tag/release без перезаписи старых
   тегов, сверка скачанного архива и отдельное обновление существующего плагина.

Сеансы выполняются на автономных копиях кандидата; аккаунтная 0.8.4 не меняется
до прохождения условий публикации. Это проверка локального Codex, не восемь
сеансов интерфейса ChatGPT Work. Реальный пользовательский Work-прогон 0.8.4
подтвердил самостоятельный выбор резервного пути после -32000 и запрета PS1;
исходный отчёт независимо пересчитан и прошёл полную схему. Прямой резервный
блок 0.8.5 проверяется в той же категории Windows-ограничений отдельным тестом.

Артефакты моделей, исходные тексты и полные журналы остаются локально. Сведения
о вакансии и научном тексте в заключительном прогоне синтетические. Результат
не экстраполируется на все запросы и модели. Принятый недобор Avito остаётся
в историческом аудите; 120/120 источников не заявляется.

## Заключительный результат

- Локально 305 тестов: 301 PASS, 4 SKIP. Проверки автономной папки,
  офлайн-работы и структуры навыка пройдены. Прямой резервный блок выполняется
  в Windows PowerShell без загрузки PS1; запрещённая политика не изменяется.
- Первые восемь сеансов: кандидат прочитан во всех, четыре неявных подключения
  состоялись. Core пропущен в одном неявном audit. В определение audit вынесено
  требование выполнить проверку до ответа. Точечный повтор того же задания
  с теми же байтами исходника и промпта в новом сеансе прошёл с Core.
- Итоговые восемь условий закрыты семью первыми сеансами и одним точечным
  повтором: четыре режима × два способа вызова. Реальные отчёты всех восьми
  выбранных ответов прошли независимую полную JSON Schema и проверку хешей.
  Это не утверждение о едином безошибочном первом прогоне 8/8.
- В create два черновика не прошли объём; агенты сами исправили их и повторили
  проверку в новых каталогах. Финальные тексты — 45 и 46 слов при лимите 45–75.
  Сравнения уложились в 120 слов, исходные файлы сохранены, выполнена собственная
  редакторская сверка всех выбранных ответов. Остаточные блокировки A8 в compare
  соответствуют намеренно испорченному второму варианту и не препятствуют анализу.
- После агентского прогона изменена только документация установки на 0.8.5;
  исполняемый Core и правила сравнения не менялись. История исходной попытки
  audit и всех промежуточных черновиков сохранена локально.

## Подтверждение в ChatGPT Work — 30 октября 2026 года

**Зафиксированный статус: рабочая стабильная база для создания и редактуры
русских текстов. Основной этап отладки выпуска 0.8.5 закрыт.**

После публикации и обновления плагина выполнен реальный пользовательский
rewrite-прогон в новом Work-чате. В запросе не назывался «Словодел» и не
передавался путь Python. Агент самостоятельно выбрал навык 0.8.5 и разрешённый
прямой резервный запуск после ошибки MCP runtime-инструмента `-32000`;
PS1 не загружался, настройки системы и зависимости не изменялись.

Независимая проверка архива свидетельств подтвердила:

- Core и проверяющий запускатель завершились с кодом 0; решение
  `draft_requires_review`, A8 `review_required`, список расхождений пуст.
- Проверены 19 записей SHA-256 в архиве из 20 файлов. Шесть скопированных
  файлов инструкций побайтно совпали с установленным стабильным выпуском.
- Шесть внутренних проверок хешей и структура отчёта прошли. Полная JSON
  Schema в Work честно обозначена как недоступная (`JSONSCHEMA_NOT_INSTALLED`);
  отдельная локальная проверка исходного отчёта с полной схемой прошла.
- Независимый пересчёт установленным Core дал идентичный JSON. Редакторская
  сверка подтвердила сохранение даты, города, исторического расписания,
  атрибуции, неопределённости и незавершённости проверки гипотезы.

Это подтверждение одного реального rewrite-сценария в Work; четыре режима и
явные/неявные вызовы проверены в Codex по протоколу выше. Статус не означает
безошибочность всех редакторских решений или полную численную совместимость
с исторической программой. Пять уровней опубликованной методологии сохранены.
