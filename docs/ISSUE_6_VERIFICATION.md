## 1. Реализация

- [morphology.py](../skills/slovodel/slovodel_core/morphology.py) — отключаемый локальный POS-анализатор; никаких сетевых запросов, встроенного словаря, токенов или платного API.
- Поддерживаются конкретные проверенные версии **pymorphy3 2.0.6** и **pymorphy3-dicts-ru 2.4.417150.4580142**. Любая другая версия → `MORPHOLOGY_VERSION_UNSUPPORTED`, отсутствие → `MORPHOLOGY_DEPENDENCY_NOT_INSTALLED`, ошибка загрузки → `MORPHOLOGY_BACKEND_UNAVAILABLE`.
- CLI `analyze.py --morphology` и `compare.py --morphology` только **после явного включения пользователем**. По умолчанию `pos_distribution=unavailable/null`, прежние A1–A4/A6–A7 и локальная A2 доступны как прежде.
- Для каждого русского токена берутся все известные словарю кандидаты: **одна** уникальная категория POS → учёт, **разные POS** → AMBIGUOUS, неизвестное словарю → OOV, остальные случаи → UNCLASSIFIED. Не выбираем первый вариант как якобы контекстно достоверный.
- 17 POS-классов с `count`/`share`, `ambiguous`/`oov`/`unclassified`, `resolved` и `coverage`. Доли считаются от всех русских токенов. Пустой текст: счётчики = 0, доли = `unavailable/null`.
- У реальных чисел фиксируются `method_id=slovodel.a5.pymorphy3.unique_pos`, `method_version=0.4.0`, `dataset_id=pymorphy3:2.0.6|pymorphy3-dicts-ru:2.4.417150.4580142`, предупреждение об отсутствии контекстной разметки.
- Важная обратная совместимость: созданные ранее локальные профили A2 по-прежнему используют **PROFILE_METHOD_VERSION=0.3.0**, даже при Core 0.4.0.
- Свежая документация: [правила A5](../skills/slovodel/references/morphology-contract.md); [лицензии](../skills/slovodel/references/morphology-licenses.md).

## 4. Ограничения и дальнейшие шаги

1. Морфология **не контекстная**: при разных потенциальных частях речи слово попадает в AMBIGUOUS, а не в вычисленную POS-категорию. Возможны OOV и частичное покрытие.
2. Словарные кандидаты, даже известные словарю, могут быть ошибочны, например для имен, омонимов, новых/разговорных слов и дефисных форм.
3. Результат не показывает намерения или эмоционального состояния автора и не связан с историческими «суггестивными» баллами.
4. Словарь с CC BY-SA — не MIT; пользователи соблюдают лицензию словаря самостоятельно, публикация исходных словарных записей отдельно ограничена.
5. Код без внешнего сетевого API; установка через pip, если выбрана, **отдельное действие пользователя**, а в CI сетевые пакеты загружаются только в тестовом задании. Сетевого sandbox ОС нет.
6. Реализация Issue #7 (защита фактов) и приватные MCP/API/VPS/n8n **не начинались**.
