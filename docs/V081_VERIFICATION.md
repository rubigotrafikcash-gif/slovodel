## Поведение и пределы проверки

Проведено чтение и согласование основного маршрута со справочниками: методология находится в SKILL.md; дополнительные примеры доступны по ссылкам; обязательного профиля бренда нет; план и тексты могут выдаваться вместе; просьба «только текст» соблюдается; недоступные исторические числа не сочиняются.

Это проверка инструкций и примеров автором изменений, **не независимый запуск модели**. Свежий сквозной прогон в авторизованных клиентах ChatGPT/Codex — `NOT_RUN`. Протоколы 0.8.0 сохраняются как исторические данные и не подтверждают качество 0.8.1. Выпуск остаётся PRE-RELEASE.

В новых тестах используются только самостоятельно составленные синтетические тексты. Полные книги, исторические таблицы, закрытая программа и тексты клиентов не добавлялись. Расчёты не подтверждают психологические эффекты или коммерческую эффективность.

## Воспроизведение

```text
python -m unittest discover -s tests -v
python scripts/release_smoke.py
python scripts/benchmark_v08.py
python scripts/offline_smoke.py
```

Для полной схемной проверки требуется jsonschema, для покрытия — coverage. Сам Core работает без этих библиотек. Машинные результаты CI сохраняются как artifacts workflow; выдача отчёта не разрешает автоматическую публикацию пользовательского текста.
