# Issue #5 — проверка нормативных частот, локальных профилей и прав на корпуса

Дата: 2026-10-15. Область: только **публичный GitHub-навык**. PR: [#15](https://github.com/rubigotrafikcash-gif/slovodel/pull/15).

## 1. Юридическое и методическое решение

**Встроенный общерусский нормативный корпус НЕ ПРИНЯТ.** Установлено:
- НКРЯ (RNC) — ограничения на коммерческое использование и распространение.
- Russian SynTagRus — CC BY-NC-SA 4.0.
- Russian GSD и Russian Taiga — CC BY-SA, но права на **первичные тексты**, обязательства производных данных и соответствие жанра цели требуют отдельной проверки.
- OpenCorpora и Wikipedia — недостаточно подтверждённой полноты прав, режима перераспространения агрегатов и репрезентативности для принятия как общей русской нормы.

Источники и подробная карта решений: [обзор корпуса/лицензий](../skills/slovodel/references/corpus-license-review.md). Паспорт отсутствия согласованной базы и условия будущей приёмки: [resources/corpora](../skills/slovodel/resources/corpora/README.md).

**Актуальный статус A2:** norm_letter_deviation всегда **unavailable/null**. Никаких таблиц стороннего происхождения, XML, wiki-дампов и текстов закрытых корпусов в репозитории нет.

## 2. Воспроизводимая реализация

- Python Core v0.3.0, полностью локальные функции в [a2.py](../skills/slovodel/slovodel_core/a2.py), [metrics.py](../skills/slovodel/slovodel_core/metrics.py), [reports.py](../skills/slovodel/slovodel_core/reports.py).
- Опциональный исполняемый [build_reference.py](../skills/slovodel/scripts/build_reference.py); вход пользователя до 1 МиБ. Нет скачивания/серверов/API.
- Источник/жанр/версия/заявленная лицензия/основание прав/точное preprocessing/SHA-256/33 счётчика/сумма — в отдельном профиле JSON. Проверки формы, версии, контрольной суммы, duplicated keys, отрицательных и булевых частот.
- Локальная база **всегда** имеет статусы profile_kind=user_supplied_non_normative и license_status=self_declared_unverified. Код не подтверждает юридическую достоверность сведений пользователя.
- Формулы p=n/N, q=b/B, delta_pp=round(100*(p-q),8), ratio=round(p/q,8) только при q>0; при N=0 оба показателя unavailable/null; при q=0 ratio unavailable/null, delta сохраняется.
- Для 33 букв 66 отдельных метрик. Каждая вычисляемая метрика включает method_id, method_version, dataset_id с sha256 профиля, единицу измерения, n, предупреждения о ненормативности. Базы меньше 10000 и тексты меньше 100 русских букв получают отдельные диагностические предупреждения (эвристические пороги, не статистическое доказательство).
- В compare один профиль для before/after; сопоставление только одинаковых method/version/dataset, delta=after-before. Неподтверждённые нормативные/исторические показатели не попадают в расчёты.
- Формат профиля: [local-reference.schema.json](../schemas/local-reference.schema.json); примеры CLI и ограничения: [a2-contract.md](../skills/slovodel/references/a2-contract.md).

## 4. Оставшиеся ограничения

- Нет официально допущенной базы для нормы русского языка. Локальный, даже большой профиль — **не общерусская норма**.
- Слова и исходные тексты не включаются в JSON, но профили, SHA-256 и агрегаты могут раскрывать характеристики исходника.
- Лицензия заявляется самим пользователем; код не предоставляет прав на чужие тексты и не проверяет внешние юридические документы.
- Нормативное сравнение жанров, статистическая значимость, доверительные интервалы, морфология, исторические методы/шкалы и фонетическая транскрипция пока **не реализованы**.
- Запуск Python не изолирован системным сетевым sandbox; выполняется только собственная локальная логика без сетевых вызовов.
- Нет изменений в n8n/VPS/Wirebot/MCP, закрытой инфраструктуре и задачах #6+.
