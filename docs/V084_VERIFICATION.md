# 0.8.4 — выбор исполняемого Python

Обнаруженный сбой: `python --version` обращался к WindowsApps и завершался
«Доступ к этому файлу из системы отсутствует». Встроенный Python 3.12.14
запускался по полному пути. В пользовательском Work-тесте 0.8.3 после этого
Core выполнился с кодом 0. Архив содержал исходник, редакцию, полный отчёт,
журнал исполнения и смысловую сверку. Независимый локальный пересчёт дал
идентичный JSON, полная JSON Schema-проверка исходного отчёта прошла.

## Исправление

- Агент получает путь Python через доступный инструмент среды, проверяет его
  и запускает Core напрямую. Пользователь не ищет путь вручную.
- Windows-запускатель `check_workflow.ps1` проверяет Python 3.10+, резервное
  стандартное расположение встроенного runtime, затем приложения из PATH.
  WindowsApps пропускается. Проба каждого кандидата ограничена пятью секундами.
- Явный путь обязателен к исполнению: если он не работает, ошибка 8, без тихой
  замены. Коды Core и ограничений объёма передаются неизменными.
- В `execution.json` записываются `python_executable` и `python_version`.
- Нет загрузки Python, установки пакетов, изменения PATH, execution policy,
  ACL, аккаунтной области распространения или передачи текстов в сеть.

Системный Windows PowerShell 5.1 на этой машине запрещает PS1. Его политика
не менялась. Штатный PowerShell 7.6.5 разрешает запуск: девять интеграционных
тестов прошли. При запрещённом PS1 инструкция использует разрешённый прямой
запуск найденного Python. Исполнение в недоступной среде не имитируется.

## Официальная документация, проверена 30 октября 2026 года

- [Skills](https://developers.openai.com/plugins/concepts/skills): пакет навыка
  может содержать инструкции, ссылки, скрипты и ресурсы.
- [Package your plugin](https://developers.openai.com/plugins/build/plugins):
  структура пакета и совместимость манифестов.
- [Plugins](https://learn.chatgpt.com/docs/plugins): новые сеансы после установки;
  hooks плагинов не поддерживаются в cloud-orchestrated Work. Поэтому hook
  не применяется к проблеме выбора Python.
- [Desktop only](https://developers.openai.com/plugins/deploy/desktop-only):
  `requires_local_executor` нужен плагину, который требует локального исполнения.
  Словодел сохраняет качественную работу без Core, поэтому это ограничение
  на весь плагин не добавляется.

Обновление ограничено выбором runtime и документацией. Новый большой корпус
и сравнение качества моделей не запускались. Локальные CLI-тесты не заменяют
проверку автоматического вызова навыка в каждом варианте ChatGPT Work.

Проверены четыре режима, код 5 изменения даты, код 7 нарушения объёма, код 3
отсутствующего входа, код 8 неподходящего Python, WindowsApps, путь с пробелами,
скопированный автономный пакет и строгая обработка native-ошибок в вызывающем
PowerShell. Изменение настройки native-ошибок ограничено областью PS1, без
изменения вызывающего сеанса или системных параметров.
