## Что не сделано и почему

- Шесть полных текстов Черепановой не перезапускались: их полные тексты не распространяются открыто.
- Независимый прогон навыка в авторизованных Codex/Claude — `NOT_RUN`; это отдельная задача после выпуска.
- В опубликованных заметках к v0.7.0 есть опечатка (грузинские буквы в слове «независимое»); файл `docs/releases/v0.7.0.md` не правился, чтобы не запустить повторно workflow публикации v0.7.0.

## Решение

Выпуск `v0.8.0` как pre-release — **только после зелёного CI на последнем коммите PR и явного согласования владельца**: слияние в `main` с изменённым `docs/releases/v0.8.0.md` автоматически публикует GitHub Release.
