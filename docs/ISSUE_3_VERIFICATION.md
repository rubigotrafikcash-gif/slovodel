## Известные ограничения и границы

- Лингвистические измерения A1–A8, нормативные корпуса, POS, подсчёт слогов/частот и фактический контроль семантики **не реализованы** в Issue #3; их нельзя рекламировать как выполненные.
- Ни программа «Диатон»/«Словодел», ни её исторические числовые шкалы не запускаются и не эмулируются.
- Метрика `token_count` в JSON присутствует как явный placeholder `unavailable` (не значение 0).
- Проверка языка не выполняется: `language=ru` — заявленная целевая область навыка.
- Для Unicode NFC нет карты смещений (`offset_map_status=not_implemented`).
- Нет защиты от символических ссылок в родительских компонентах пути, не создана изолированная песочница ОС.
- Временные файлы и тексты не записываются нашим ядром без `--output`, но stdout/окружение AI-агента может хранить результат. Размер и SHA-256 остаются потенциально чувствительными метаданными.
- Проверка HTTP/сети — только статический импорт-контроль плюс отсутствие сетевых вызовов в текущем коде; программа не гарантирует ограничений сети на уровне операционной системы.
- Публичная текстовая редактура без установленного Python остаётся самостоятельным режимом.
